# SaintSoft Landing Page

Landing page premium para SaintSoft, empresa líder en desarrollo de software corporativo.

## 🚀 Características

- ✨ Diseño moderno y minimalista inspirado en Stripe, Vercel y Linear
- 🎨 Modo oscuro con transiciones suaves
- 🎭 Animaciones sofisticadas con Framer Motion
- 📱 Totalmente responsive (Mobile-First)
- ⚡ Optimizado para rendimiento (Next.js 16 + Turbopack)
- 🎯 Efecto de seguimiento del mouse en desktop
- 🔵 Paleta de colores azul profesional
- 💎 Cards con efectos de profundidad y bordes animados

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 16.2.6
- **UI:** React 19.2.4
- **Estilos:** Tailwind CSS 4
- **Animaciones:** Framer Motion
- **Iconos:** Lucide React
- **Lenguaje:** TypeScript 5

## 📦 Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en modo desarrollo
npm run dev

# Compilar para producción
npm run build

# Iniciar servidor de producción
npm start
```

## 🎨 Características de Diseño

### Modo Oscuro
- Toggle de tema en el header
- Persistencia en localStorage
- Detección automática de preferencias del sistema
- Transiciones suaves entre temas

### Animaciones
- Cards con bordes animados y efectos de brillo
- Partículas flotantes en el Hero
- Efecto de seguimiento del mouse (solo desktop)
- Transiciones suaves en scroll
- Hover states interactivos

### Secciones
1. **Hero** - Propuesta de valor principal con partículas animadas
2. **Trusted By** - Logos de clientes
3. **Servicios** - 8 servicios core con cards animados
4. **Beneficios** - 4 beneficios clave
5. **Proceso** - Timeline de metodología
6. **Tecnologías** - Stack tecnológico
7. **Casos de Éxito** - 3 casos destacados con métricas
8. **Testimonios** - Validación de clientes
9. **Stats** - KPIs con números animados
10. **CTA** - Llamado a la acción
11. **FAQ** - Preguntas frecuentes con acordeón
12. **Contacto** - Formulario y información
13. **Footer** - Navegación y redes sociales
